Detailed Description

Harmonia's DX7 mode: one DX7 voice played by Dexed's msfa FM core (Apache 2.0, see dx7/README.md).

A DX7 preset is the 145 DX7 parameters of the charter, i.e. one DX7 voice exactly as stored in a cartridge: no conversion. Each note is driven like the AI's reference renderer (HARMONIA/native/dx7/dx7_render.cpp in Harmonia-AI), so the plugin plays the sounds the v3 models learned: 64-sample blocks, the voice's own LFO, key-up on a block boundary, Dexed's DC filter, DX7 keyboard velocity. No allocation while rendering.
