Detailed Description

Authentication page — sign in with identifier + password.

Visual design mirrors the WelcomePage (dark gradient, animated waves, logo PNG without container). Buttons use AuthPageLookAndFeel.

Keyboard navigation:

  • Tab / Shift+Tab : identifier -> password -> Sign in -> Back (loops)
  • Enter in the identifier field : jumps to the password field
  • Enter in the password field : submits the form
  • Enter / Space on a focused button : presses it The identifier field takes the focus when the page is shown.
