Detailed Description

Panneau « Keyboard » : le piano du plugin, dans le même cadre que les autres sections.

( ● KEYBOARD [◂ C3 ▸] [◂ VEL 80% ▸] [AZERTY] ) ( ┌───────────────────── touches sombres ──────────────────────┐ ) ( │ zone jouable au clavier d'ordinateur : lettres + liseré │ ) ( └─────────────── le reste estompé, sans flèches ──────────────┘ )

Les chips reprennent les raccourcis clavier (W/X octave, C/V vélocité, B disposition) à la souris, et se mettent à jour quand on utilise ces raccourcis.
