Layout APVTS complet, genere depuis le charter (un groupe par module / operateur DX7).

Layout complet v3 (groupes par module et par operateur DX7).

Creates the synthesizer parameter layout.

Builds all APVTS parameters used by the synthesizer.

Includes:

  • Float parameters
  • Choice parameters
  • Labels
  • Default values
  • Parameter ranges
  • Skew factors

Parameter Categories:

  • Oscillators
  • Filter
  • Envelopes
  • Modulation
  • Effects
Returns
Fully initialized JUCE parameter layout.

Valeur lisible (knobs, hôte) : 2, 1 ou 0 décimales selon la grandeur, kHz / s au-delà de 1000, un signe sur les paramètres bipolaires.

Ex. "20.0 kHz", "2.50 s", "+7 st".

float midpoint )
inline

Plage logarithmique (meme formule que le charter pour ses skews).

Identique a la v1 (le charter v3 precalcule deja ses skews avec la meme formule).

Creates a logarithmic parameter range.

Used for perceptually logarithmic parameters:

  • Frequencies
  • Envelope times
  • LFO rates

JUCE internally uses a skew factor to create non-linear parameter scaling.

Parameters
minVMinimum value.
maxVMaximum value.
midpointDesired midpoint value.
Returns
Configured logarithmic range.
