◆ MainComponent()

MainComponent::MainComponent ( HarmoniaAudioProcessor & p,
BackendManager & be,
const UserSession & session,
const AIModelList & models = {} )

Constructs the main plugin interface.

Initializes:

  • Look and feel
  • Visual sections
  • Parameter controls
  • Oscilloscope routing
  • Preset management
  • AI generation tools
  • Palette restoration / sync callbacks
  • History callbacks (select / delete / clear)
Parameters
pReference to the audio processor.
beBackend manager used for AI and session communication.
sessionCurrent authenticated user session.
modelsOptional initial AI model list. Usually empty: the list is fetched asynchronously by refreshModelsAsync() right after construction (connected users only).

◆ refreshModelsAsync()

void MainComponent::refreshModelsAsync ( )
private

Fetches the AI model list (GET /ai/models) on a background thread and updates the header menu when it arrives.

Does nothing for guests. On network failure the header keeps its current state and generation still works through the "latest" model.
