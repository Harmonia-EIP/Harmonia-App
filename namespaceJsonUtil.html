Detailed Description

Accès JSON qui ne lèvent jamais d'exception.

json::value("clé", défaut) lève une type_error si la clé existe mais avec un autre type (ex. "token": null). Dans un plugin, une exception non attrapée = crash du DAW, donc tout passe par ces helpers.
