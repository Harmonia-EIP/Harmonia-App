Detailed Description

Toast Harmonia : carte sombre avec lueur d'accent, affichée quelques secondes puis disparue toute seule.

Header-only.

HarmoniaAlert::error (this, "Authentication error", message); HarmoniaAlert::error (this, "Authentication error", message, HarmoniaAlert::Position::Center); HarmoniaAlert::setDefaultPosition (HarmoniaAlert::Position::TopRight);

  • Survol souris : le compte à rebours est mis en pause.
  • Clic : ferme tout de suite.
  • Même message déjà affiché : le timer est simplement relancé (pas de doublon).
