Detailed Description

Point d'entree unique des parametres Harmonia (46 analogiques + 145 DX7 + engine).

Couche de compatibilité v1 -> v3.

Centralized synthesizer parameter definitions and APVTS layout creation.

Tout est lu dans HarmoniaCharter.h (genere) : IDs, plages, skews, defauts, groupes. Ce fichier ne contient que la glue JUCE :

  • IDs:: noms CamelCase des parametres analogiques (+ engine)
  • orderedIds() les 20 IDs historiques, dans l'ordre v1
  • orderedAnalogIds() les 46 IDs analogiques, dans l'ordre du charter
  • createLayout() layout APVTS complet, groupes par module / operateur DX7
  • AtomicRefs pointeurs atomiques pour le DSP (refs.filterCutoff->load())

Les IDs ne sont PAS ecrits en dur : un static_assert verifie a la compilation que chaque nom correspond bien a l'ID du charter.

Pour ajouter un parametre analogique : regenerer le charter, puis ajouter une ligne X(nomCamelCase, id_snake_case) dans HARMONIA_ANALOG_LIST (a la fin, dans l'ordre du charter).

Chargement de presets : le charter fournit indexOf(id), snap(), fromNormalized() et upgradeFromV2(); un preset incomplet (20 params au lieu de 46+) se charge en ne touchant que les IDs presents, les autres gardent leur valeur par defaut.

Unites v3 : filterEnvAmount en octaves (-10..10), lfoToPitch en cents (0..1200), lfoToCutoff en octaves (0..4).

This file defines every parameter used by the Harmonia synthesizer.

Responsibilities:

  • Declaring parameter identifiers
  • Creating the AudioProcessorValueTreeState layout
  • Providing ordered parameter access
  • Defining logarithmic parameter ranges
  • Providing fast atomic parameter references

Main DSP Sections:

  • Oscillators
  • Noise generator
  • Filter
  • ADSR envelopes
  • Filter envelope
  • LFO modulation
  • Velocity modulation
  • Distortion
  • Reverb

Architecture: IDs namespace: Contains all parameter string identifiers.

createLayout(): Builds the JUCE parameter tree.

AtomicRefs: Stores raw atomic parameter pointers for real-time safe DSP access.

Expose l'API de la v1 (IDs::, orderedIds(), makeLogRange(), createLayout(), AtomicRefs avec pointeurs nommés) au-dessus du charter v3 généré.

Les IDs ne sont PAS écrits en dur : ils sont lus dans HarmoniaCharter::params via l'enum HarmoniaCharter::analog::Index. Un static_assert vérifie à la compilation que le nom attendu correspond bien à l'ID du charter.

Pour ajouter un paramètre analogique : régénérer le charter, puis ajouter une ligne X(nomCamelCase, id_snake_case) dans HARMONIA_ANALOG_LIST.

NB : en v3 certaines valeurs ont changé d'unité (voir notes de migration) : filterEnvAmount : octaves (-10..10) lfoToPitch : cents (0..1200) lfoToCutoff : octaves (0..4)
