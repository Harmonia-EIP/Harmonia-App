Detailed Description

Étage de sortie du plugin (C++ pur, sans JUCE) : volume puis limiteur doux.

Le limiteur est transparent sous -1 dBFS ; au-dessus, il arrondit les crêtes (courbe tanh) sans jamais dépasser 0 dBFS. Il protège des presets générés ou aléatoires trop forts (unisson, résonance, distorsion empilés), pas un outil de son.
