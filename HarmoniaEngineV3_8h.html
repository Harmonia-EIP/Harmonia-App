Detailed Description

Harmonia v3 analog engine, plain C++17 (no JUCE): the sound the v3 AI models are trained on.

Port of the reference implementation HARMONIA/src/synth/engine_v3.py (Harmonia-AI). Per voice: 2 oscillators (sine, triangle, band-limited saw and pulse) x unison (1..16 voices) + noise -> state-variable filter (12 / 24 dB) -> drive -> amplifier, computed at twice the sample rate and brought back by a half-band filter; then, on the mix, chorus -> delay -> reverb (feedback delay network). Parameters are physical values in charter order (HarmoniaCharter::analog::Index).

Real-time safe: memory is allocated in prepare(), never while rendering.
