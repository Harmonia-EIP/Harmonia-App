Detailed Description

Rotary knob UI component linked to an APVTS parameter.

Features:

  • Rotary interaction
  • Optional bipolar mode
  • Value readout display
  • Fast tweak detection
  • APVTS synchronization
  • Lock state (Refine mode): padlock next to the caption, click the caption to toggle. Locked = brighter padlock + slightly brighter caption (no layout shift, no hue change).
