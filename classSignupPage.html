Detailed Description

Authentication page — create a new Harmonia account.

Visual design mirrors LoginPage and WelcomePage (dark gradient, animated waves, logo PNG without container). Buttons use AuthPageLookAndFeel.

Keyboard navigation:

  • Tab / Shift+Tab : username -> first name -> last name -> email -> password -> Create account -> Back (loops)
  • Enter in a field : jumps to the next field
  • Enter in the password field : submits the form
  • Enter / Space on a focused button : presses it The username field takes the focus when the page is shown.
