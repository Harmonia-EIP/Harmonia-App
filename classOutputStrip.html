Detailed Description

Bandeau de sortie compact (même cadre et même ombre que les SectionPanel) : titre et valeur empilés à gauche, slider + vumètre sur toute la largeur restante.

( ● OUTPUT [=========o-----------—] ) ( -6.0 dB [▮▮▮▮▮▮▮▮▮▮▮ ] )

Le volume est hors charte (HarmoniaParams::Output) : ni IA, ni presets, ni aléatoire. Double-clic sur le slider : retour à 0 dB.
