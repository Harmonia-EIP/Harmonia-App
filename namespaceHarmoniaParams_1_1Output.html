Detailed Description

Volume de sortie du plugin : un réglage d'écoute, pas une partie du son.

Il n'est PAS dans la charte : l'IA ne le génère pas et ne le reçoit pas (Refine), les presets ne le sauvegardent pas, le bouton aléatoire et le chargement d'un preset n'y touchent pas. Automatisable dans le DAW, retenu avec le projet.
